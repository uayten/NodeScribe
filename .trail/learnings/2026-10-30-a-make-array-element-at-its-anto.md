## Decided
The builder holds a Make Array's arguments until its output has a consumer, then applies links before literals (`ApplyDeferredElements`). `UK2Node_MakeContainer::PropagatePinType` resets a default set on a wildcard pin, and the first linked element would otherwise fix the array's type.

## Watch out
`Make Array ([1] = ?)` in the text comes back as `[1] = ObjectTypeQuery1`: typing the pin sets its value but not `AutogeneratedDefaultValue`, so the reader sees a changed value. It is stable on a second round trip, so write tests against the reading, not the text given.
A warning in `project_graphs_round_trip` covers the Blueprint, not the error: `GA_Investida` left the Object Types errors behind and still fails for `Add` and `Contains Item`.
